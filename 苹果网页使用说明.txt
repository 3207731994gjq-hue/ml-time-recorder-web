毫升时间记录器——苹果手机使用说明
==================================

这个版本是“主屏幕网页应用”，不需要 App Store、苹果电脑、数据线或安装 IPA。
程序本身不会联网传输记录；你的时间和毫升数据只保存在当前 iPhone 的 Safari 中。

一、支持哪些苹果手机
--------------------
建议使用 iOS 12 或更高版本的 iPhone/iPad，以及系统自带 Safari。
网页使用普通 HTML、CSS、JavaScript，没有外部框架、广告、账户或第三方接口。
过于老旧、已经无法正常使用现代 Safari 的设备，无法承诺兼容。

二、第一次安装
--------------
1. 在 iPhone 上用 Safari 打开发布后的 HTTPS 网页地址。
2. 点击 Safari 的“分享”按钮（方框上面一个向上的箭头）。
3. 向下找到并点击“添加到主屏幕”。
4. 名称保留“记录毫升”，点击右上角“添加”。
5. 手机桌面会出现“记录毫升”图标。

注意：必须使用 Safari 添加。微信、QQ 等软件内置浏览器通常没有“添加到主屏幕”。

三、平时记录
------------
1. 点击手机桌面的“记录毫升”图标。
2. 页面会自动弹出毫升选择。
3. 可用减号、加号、滑块或常用数字选择 10–300 ml，步长是 10 ml。
4. 点击“记录当前时间”。确认的那一刻会按手机本机时间保存，准确到秒。

四、补记和修改
--------------
在“记录”页点“补记时间”，或在“明细”页点“补记”，可以填写过去的日期、准确时间和毫升数。
未来时间不能保存。已有记录可以编辑，也可以删除。

五、查看统计
------------
“统计”页可以切换最近7天、本周、上周、30天和全部。
可查看准确总量、准确次数、平均每次毫升数、平均时刻、平均间隔、每天平均次数和每日图表。
平均时刻使用跨午夜算法，例如 23:50 和 00:10 的平均值是约 00:00，而不是中午。

六、保护数据
------------
记录只存在当前手机、当前 Safari 的本地存储里，不会自动同步，也不会上传。
删除 Safari 网站数据、恢复手机、换手机或卸载网页图标前，请先到“备份”页导出 JSON。
在 iPhone 上导出时会优先弹出系统分享菜单，请选择“存储到文件”。
CSV 可用 Excel、WPS 或 Numbers 打开；恢复数据必须选择 JSON 文件。
恢复 JSON 时会自动跳过重复记录。

七、离线使用
------------
第一次通过 HTTPS 完整打开网页后，Safari 会缓存程序文件。以后短时没有网络时通常仍可打开和记录。
本地 HTML 文件或聊天软件里直接粘贴的网页代码不能完成安装；iPhone 必须先打开一个 HTTPS 网页地址。

隐私说明
--------
程序文件只包含界面和计算代码，不包含你的任何记录。
程序不会请求通讯录、相册、位置、麦克风、相机、Apple ID 或 GitHub 账户。
